# Room Code Display

A simple BepInEx mod for Gorilla Tag that shows your current room code on your desktop to be mainly used for streaming.

## Features
* Shows on desktop, hidden inside your headset
* Press **L3 + R3** to toggle between the code and hidden
* Click and drag the text anywhere on your screen

## Controls
* **L3 + R3:** Toggle hidden state
* **Left Click + Drag:** Move text

## Installation
1. Make sure you have **BepInEx** installed for Gorilla Tag.
2. Download the latest release `.dll` from the [Releases](https://github.com/YourUsername/YourRepoName/releases) page.
3. Create a folder inside of your `Gorilla Tag/BepInEx/plugins/` folder named `RoomCodeDisplay`
4. Drop `RoomCodeDisplay.dll` into your newly created folder.
